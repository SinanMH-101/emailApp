# Email Generator App (Java GUI)

This is a small personal project I made during my first year in university.

It's is a simple Java Swing application that creates professional email addresses and secure random passwords based on user input. The application takes the user's first name, last name, and department selection, and then generates an email address and password in a clean, user-friendly interface.

This project helped me strengthen my understanding of:

- Java Swing: How to build GUIs with layout managers, text fields, combo boxes, and buttons.
- OOP Concepts: Encapsulation, constructors, and method abstraction in Java.
- Code Separation: Keeping logic (in Email.java) and interface (in EmailApp.java) separate for better design.
- Event-Driven Programming: Using listeners to handle user actions and update UI dynamically.
- UI/UX Basics: Structuring a clean layout and improving user readability.



## Features

- Collects user input via a graphical interface
- Allows selection of department via dropdown
- Automatically generates:
  - Company-style email address
  - Secure 10-character password
- Displays output in a readable format



## Technologies Used

- Java 
- Java Swing (GUI)
- Object-Oriented Programming principles


##  How to Run

1. **Clone or download** the repository.
2. Open the src folder in VS code and run the EmailApp.java file
